Python Tkinter 視窗程式設計

完整課程講義、精選範例與作業速查指引

CH01. 基礎視窗創建與三大排版組合 (pack, place, grid)

本章節介紹如何初始化一個空白視窗，並透過 Python 的 for 迴圈動態建立多個組件，最後深入比較 Tkinter 的三種元件定位擺放方法。

1.1 創建最基本的空白視窗

這是所有 Tkinter 視窗程式的起點，包含載入函式庫、建立主物件、設定標題與啟動無窮主循環。

from tkinter import * # 載入 Tkinter 函式庫
root = Tk()                # 建立一個視窗主物件
root.title("新視窗")       # 設定視窗上方顯示的名稱
root.mainloop()            # 讓視窗持續執行，監聽事件

1.2 設定視窗大小與螢幕出現位置

語法格式：root.geometry("長度x寬度+水平座標+垂直座標")

注意：長寬與座標中間是用小寫英文字母 x 連接，而非乘號。座標 +0+0 代表螢幕的左上角。
from tkinter import *
root = Tk()
root.title("新視窗")
# 設定視窗大小為 450x300 像素，並強制出現在螢幕左上方 (0,0) 位置
root.geometry("450x300+0+0")
root.mainloop()

1.3 三大排版定位方式詳細解析

A. pack() 排版方法 — 自動依序順流排列

適合簡單的線性排版（上到下或左到右）。常用參數如下：

  • side：設定組件對齊方向。可選值有 TOP (預設)、BOTTOM、LEFT、RIGHT。
  • padx / pady：設定組件與相鄰物件的「外部水平/垂直間距」單位。
# 範例一：透過 for 迴圈與 pack 快速建立 5 個垂直排列的 Label
for i in range(5):
    Label(root, text="pack" + str(i)).pack()

# 範例二：設定不同的方向對齊排列
loc = [RIGHT, BOTTOM, LEFT, TOP]
for i in range(4):
    Label(root, text="pack" + str(i)).pack(side=loc[i])

# 範例三：設定各種方向的內外顏色及間距
Label(root, text="pack1", bg="yellow").pack(side=LEFT, padx=0)
Label(root, text="pack2", bg="green").pack(expand=0, side=LEFT, padx=10) # 水平差 10 單位
Label(root, text="pack3", bg="red").pack(side=BOTTOM, padx=30)          # 水平差 30 單位
Label(root, text="pack4", bg="white").pack(side=BOTTOM, pady=30)        # 垂直差 30 單位

B. place() 排版方法 — 絕對座標精準定位

適合固定視窗大小，且需要非常精確、不隨視窗縮放改變的位置設計。

# 語法基礎
Label(root, text="Label1").place(x=0, y=0)

# 綜合範例：利用 for 迴圈每隔 80 像素橫向擺放一個標籤
root.geometry("400x300")
for i in range(5):
    Label(root, text="Label" + str(i)).place(x=80 * i)

C. grid() 排版方法 — 網格/表格矩陣排列

如同 Excel 表格，將視窗劃分為列(row)與欄(column)。如果不指定橫列與直欄，預設會從 row=0, column=0 開始擺放。

lb0 = Label(root, text="Label0")
lb1 = Label(root, text="Label1")
lb2 = Label(root, text="Label2")

lb0.grid()                   # 預設位置：row=0, column=0
lb1.grid(row=0, column=1)    # 右側：row=0, column=1
lb2.grid(row=1, column=0)    # 下方：row=1, column=0

課堂作業練習：CH01_網格排列練習

請嘗試使用 grid() 網格排版方法建立 6 個 Label 元件，並按照以下矩陣結構進行精準擺放：

[Label0] [Label1]
[Label2] [Label3]
[Label4] [Label5]

提示：Label(root, text="Label0").grid(row=0, column=0)，依此類推，利用雙層或單層迴圈與算術運算快速達成。

CH02. Button 按鈕元件外觀美化與行為事件控制

按鈕是用戶互動的核心。本章節介紹如何建立按鈕、美化按鈕樣式、觸發特定事件函式，以及如何讓按鈕動態隱藏消失。

2.1 按鈕基本創建語法

# 方式一：先宣告變數再封裝（便於之後用變數控制按鈕屬性）
b1 = Button(root, text="click!")
b1.pack()

# 方式二：直接宣告並一行完成封裝（適合單純點擊不需再動態變更的按鈕）
Button(root, text="click!").pack()

2.2 美化參數速查 (常用外框、圖示、大小、顏色)

美化屬性 功能指令語法 可用參數值說明
外框立體效果
relief		 Button(root, text="OK", relief=FLAT) FLAT (平坦), RAISED (凸起-預設), SUNKEN (凹陷), GROOVE (溝槽), RIDGE (脊狀), SOLID (單線框)
按鈕大小
width / height		 Button(root, text="botton", width=10, height=2) 數值單位。注意：對文字按鈕而言，單位是字元數而非像素點。
色彩設定
bg / fg		 Button(root, bg="black", fg="white") bg 為按鈕背景色，fg 為文字前景顏色。支援英文單字或 #RRGGBB 十六進位色碼。
內建圖示標誌
bitmap		 Button(root, bitmap="question") 常見系統圖示：error, hourglass, info, questhead, question, warning, gray12, gray25, gray50, gray75
圖文並存方位
compound		 Button(root, text="標題", compound="bottom", bitmap="error") 決定圖示相對於文字的位置。可選：top, bottom, left, right, center
文字顯示錨點
anchor		 Button(root, text="文字", anchor="nw", width=10, height=4) 當按鈕空間大於文字時，決定文字靠哪邊。方位指令：n, s, e, w, ne, nw, se, sw, center
邊框粗細

按鈕可用狀態
state		 Button(root, text="按鈕", state="disabled") normal (正常可點擊狀態), active (當滑鼠懸停或點擊時的活躍狀態), disabled (變灰、無法點擊狀態)

2.3 透過按鈕觸發事件與變數動態顯示

# 1. 綁定基本無參數事件命令
def b1_function():
    print("使用者按下了 YES!")

Button(root, text="YES!", command=b1_function).pack(side="left")

# 2. 按鈕文字動態即時顯示 (使用 StringVar)
def changeText():
    if b["text"] == "text":
        v.set("change")        # 變動字串變數設為 change
    else:
        v.set("text")          # 變動字串變數設為 text

v = StringVar()                # 宣告一個 Tkinter 專用動態字串變數
b = Button(root, textvariable=v, command=changeText)
v.set("text")                  # 初始文字設為 text
b.pack()

# 3. 動態改變另一個按鈕的狀態 (config 方法應用)
e = StringVar()                # 變動文字變數，用來即時連動按鈕2的文字
e.set("可按")                   # 預設按鈕2顯示的文字為「可按」
count = 0                      # 整數變數，當作狀態計數器（切換 0 或 1）

def click():
    global count               # 使用全域的 count 整數變數
    if count == 0:
        Button2.config(state="disabled")  # config可以用於動態修改元件的屬性
        e.set("不可按")
        count += 1
    else:
        Button2.config(state="active")
        e.set("可按")
        count = 0

# 建立負責觸發狀態改變的控制按鈕
Button1 = Button(root, text="change", command=click)
Button1.pack()

# 建立被動受控制狀態與文字的按鈕
Button2 = Button(root, textvariable=e)
Button2.pack()

2.4 元件擦除與隱藏 (pack_forget / grid_forget)

結合滑鼠按鍵點擊事件綁定 bind，可以使元件從畫面中徹底消失隱藏。

# 元件點擊後立即自行消失
def hide_me(event):
    event.widget.pack_forget() # 如果是用 pack 排版，使用 pack_forget() 擦除
    # event.widget.grid_forget() # 如果是用 grid 排版，則使用 grid_forget() 

b1 = Button(root, text="點我消失")
b1.bind("<Button-1>", hide_me) # 綁定滑鼠左鍵點擊事件 (<Button-1>)
b1.pack()

課堂作業練習：CH02_按鈕文字方位循環移動

設計一個大小設定為 width=30, height=5 的大按鈕，初始預設文字位置在右方（anchor="e"）。當使用者每點擊一次按鈕，按鈕內的文字就會按照順時針方位進行循環切換：

e → se → s → sw → w → nw → n → ne → center → 回到 e

提示：在回呼函式中使用 Button1.config(anchor=loc[count]) 進行即時修改。

CH02-2. 進階回呼函式 (Callback Function) 與多變數傳參陷阱解決方案

當我們希望按鈕點擊後觸發的函式能夠傳入參數（例如九宮格按鈕點擊時要傳入各自的座標值），直接寫 command=b_function(1) 會導致視窗還沒開好，函式就立刻自動執行完畢的重大錯誤。

3.1 使用 Lambda 運算式傳遞參數

# 正確的單一按鈕帶參數傳遞寫法
def b_function(myinput):
    print("您輸入的是:", myinput)

Button(root, text="YES!", command=lambda: b_function(1)).pack(side="left")
Button(root, text="NO!", command=lambda: b_function(2)).pack(side="right")

3.2 迴圈中的多按鈕傳參「嚴重陷阱」與兩種正確解法

經典錯誤：如果在 for 迴圈中直接使用 command=lambda: b_function(myrow, mycol)，因為變數閉包特性，無論你點擊哪一個按鈕，輸出結果全部都會是最後一圈的數值。
# 正確解法一：在 lambda 中使用區域預設變數攔截當前值 (最推薦，講義第11頁)
def b_function(r,c):
    print(f"您按下了第 {r} 列，第 {c} 欄的按鈕")

for b in range(9):
    myrow = int(b / 3)
    mycol = b % 3
    # 關鍵點：x=myrow, y=mycol 會在按鈕建立時將當前數值保存下來
    Button(root, text=b, command=lambda x=myrow, y=mycol: b_function(x, y)).grid(row=myrow, column=mycol)

# 正確解法二：使用 functools 的 partial 偏函式方法 (講義第12頁)
from functools import partial

def b_function(r,c):
    print(f"您按下了第 {r} 列，第 {c} 欄的按鈕")

for b in range(9):
    myrow = int(b / 3)
    mycol = b % 3
    Button(root, text=b, command=partial(b_function, myrow, mycol)).grid(row=myrow, column=mycol)

CH02-3. Frame 框架組件排版藝術與填滿縮放參數 (fill & expand)

Frame（框架組件）是一個矩形區域。它的最大作用是將視窗內部切割為不同的區塊，並將相關組件分組放入，是高階視覺化介面不可或缺的排版利器。

4.1 基本 Frame 劃分與元件嵌入

app = Tk()
app.geometry("400x150")

# 建立一個橘色帶凹陷效果的左側控制框架
frame1 = Frame(app, bg="orange", bd=10, relief=SUNKEN)
frame1.pack(side="left")
# 將按鈕放入 frame1 中，而不是放入主視窗 app 
button1 = Button(frame1, text="控制1").pack(side="top")
button2 = Button(frame1, text="控制2").pack(side="bottom")

# 建立一個右側格線排版的藍色資訊框架
frame2 = Frame(app, bg="blue")
frame2.pack(side="right")
button3 = Button(frame2, text="網格1").grid(row=0, column=0)
button4 = Button(frame2, text="網格2").grid(row=0, column=1)

4.2 避免框架縮水與自動放大：pack_propagate、fill、expand

  • f.pack_propagate(0)：極度重要！預設情況下，Frame 的大小會被內部放入的組件擠壓而自動變小（失去原本設定的 width/height 效果）。呼叫 pack_propagate(0) 即可強制關閉這個預設連動，維持 Frame 原本設定的大尺寸。
  • fill：控制組件如何填滿分配給它的剩餘空間。可選 X（水平填滿）、Y（垂直填滿）、BOTH（水平與垂直皆全填滿）。
  • expand=1：分配視窗多餘的空白放大空間給該元件。常與 fill=BOTH 搭配達到視窗大小改變時，組件跟著自動拉伸放大的效果。
# 經典應用範例：使按鈕完美填滿並隨著視窗無縫放大
Button(root, text='隨著視窗自動放大填滿的按鈕', bg='green').pack(expand=1, fill=BOTH)

高階綜合專題作業：CH02-3_九宮格按鈕走迷宮程式設計

請結合 Frame、grid() 網格排版以及 StringVar 狀態追蹤，設計出一個如講義第18~20頁所示的經典「走迷宮遊戲」：

  • 上方迷宮區域：使用 Text 或 Label 顯示迷宮地圖（包含目前位置 @、無法行走的牆壁 #、終點 X）。建議將地圖框架加上 bd=5, relief=RAISED 外框。
  • 中間計數器：即時顯示「行走步數：N」。
  • 下方移動控制介面：用一個獨立的 Frame 包裹 8 方向按鈕（NW, N, NE, W, E, SW, S, SE），預設該 Frame 邊界平時為藍色。
  • 遊戲邏輯：點選方向按鈕使 @ 移動。如果使用者點選到牆壁或出界，下方的 Frame 邊界立刻動態變成紅色，且步數不增加；順利抵達終點時，介面外圍改為綠色，且所有按鈕變為 disabled 無法再移動。

CH03. Label 標籤組件多元應用與計時器 (Timer) 執行緒控制

Label 主要用於展示靜態文字、格式化多行訊息或圖片。透過 after() 方法或 threading.Timer，可以輕易做出定時自動更新的跑馬燈或計時器系統。

5.1 字型格式化與多行訊息自動換行

label = Label(root, text="welcome to KUAS", bg="yellow", anchor="s", justify="left")
# 設定字型為 arial、大小 20 像素、斜體 (italic) 效果
# 效果可用：normal, bold, italic, underline, overstrike
label["font"] = ("arial", 20, "italic")

# 多行長文字自動換行設定
Label(root, text="歡迎來到這門進階視窗程式設計課程", 
      width=10, height=10, 
      wraplength=60,       # 設定每隔 60 個單位寬度自動強制換行
      justify="left",      # 多行文字靠左對齊
      anchor="s"           # 整塊文字區對齊標籤底部
).pack()

5.2 載入外部 GIF 圖片至標籤中

注意：Tkinter 原生的 PhotoImage 在舊版本中主要支援 .gif 或 .png 格式。路徑字串中若含有反斜線，建議加 r 或改用正斜線。
logo = PhotoImage(file="C:/KUAS.gif")            # 載入圖片檔案
Label(root, image=logo).pack(side="right")       # 將圖片塞入標籤並靠右排列
Label(root, text="校徽說明").pack(side="left")

5.3 兩種計時器 (Timer) 實現方式比較

方法一：利用元件內建的 after() 方法 (非同步單執行緒，講義第8頁)

counter = 0
def count():
    global counter
    counter += 1
    label.config(text=str(counter))   # 更新標籤文字
    label.after(1000, count)          # 延遲 1000 毫秒 (1秒) 後，再次遞迴呼叫自己

label = Label(root, fg="green")
label.pack()
count()                               # 啟動計時

方法二：利用 threading 多執行緒核心 Timer (支援帶參數傳遞，講義第1222頁)

from threading import Timer

t = None
counter = 1

def change_time(a, b):
    global counter, t
    counter += 1
    labelText.set(str(counter))
    # 每一秒在新執行緒中重複建立並啟動計時器，同時將參數累加傳入
    t = Timer(1, change_time, [a+1, b+1])
    print(f"目前參數狀態 A: {a+1}, B: {b+1}")
    t.start()

def pause():
    global t
    t.cancel()                        # 強制關閉並取消定時器執行緒，避免程式關閉後背後還在跑
    root.destroy()

root = Tk()
labelText = StringVar()
labelText.set(str(counter))
Label(root, textvariable=labelText).pack()
Button(root, text="安全退出並關閉執行緒", command=pause).pack()

t = Timer(1, change_time, [1, 2])     # 初始建立：1秒後執行 change_time，傳入引數 [1, 2]
t.start()                             # 啟動執行緒
root.mainloop()

CH04. Entry 單行文字輸入框與 Text 多行文字區塊 (含 Scrollbar 完美結合)

輸入框是用戶提交資料的核心。單行文字使用 Entry，多行文本與大片文章展示則使用 Text，且大文本務必搭配 Scrollbar 捲動軸以防超出視窗。

6.1 Entry 輸入框讀寫與密碼遮罩設定

# 核心概念：Entry 無法直接用 text 參數給予預設值，一定要透過 textvariable 綁定
e = StringVar()
entry = Entry(root, textvariable=e)
e.set("請在此輸入文字...")              # 使用 set() 寫入初始預設文字
entry.pack()

print(entry.get())                    # 方式一：直接從元件本體 get() 讀取內容
print(e.get())                        # 方式二：從綁定的字串變數 get() 讀取內容（完全相同）

# 實用特殊設定
entry["state"] = "readonly"           # 設定輸入框為「唯讀狀態」，不可輸入修改
entry["show"] = "*"                   # 設定字元遮罩符號，任何輸入自動變 * 號（密碼框專用）

6.2 Text 多行文本組件基礎

Text 組件的座標起點是 "1.0"（代表第 1 列、第 0 個字元位置）。

t = Text(root, height=10, width=40)
for i in range(5):
    t.insert("1.0", str(i) + " 新的一行\n") # 一直從第一列最開頭插入新字串，舊內容會被往下推

print(t.get("1.0", "1.2"))            # 讀取並列印出第一列的前兩個字元
print(t.get("1.0", END))              # 讀取並列印出從頭到結尾(END)的所有文字內容
t.pack()

6.3 Text 與 Scrollbar (捲動軸) 雙向綁定標準黃金模板

要讓捲動軸和文字區完美連動，兩者必須互相註冊。請牢記以下對稱綁定步驟：

s = Scrollbar(root)                    # 1. 建立捲動軸
t = Text(root, height=5, width=20)     # 2. 建立文字多行區

s.pack(side=RIGHT, fill=Y)             # 3. 捲動軸放在右側，並且垂直方向填滿
t.pack(side=LEFT, fill=BOTH, expand=1) # 4. 文字區放在左側，完全填滿剩餘空間

s.config(command=t.yview)              # 5. 綁定動作：當拉動捲動軸時，改變 Text 的 y 軸視角
t.config(yscrollcommand=s.set)         # 6. 綁定動作：當在 Text 內滾動滑鼠或換行時，同步更新捲動軸滑塊位置

long_string = "大量長文本內容..."
t.insert("1.0", long_string)
mainloop()

CH05. Radiobutton 單選按鈕群組設計與大氣 Button 樣式切換

單選按鈕用於多選一的場景。其核心邏輯是：同一個群組內的所有 Radiobutton 物件，必須綁定同一個 variable，但是設定各不相同的 value。

7.1 建立單選按鈕群組與取得選取值

v = IntVar()                           # 建立一個共享的整數變數
v.set(0)                               # 預設選中 value=0 的那個選項

def show_choice():
    print("目前使用者選中的項目編號是:", v.get())

arr = ["電子系", "電機系", "資工系"]
for i in range(3):
    Radiobutton(root,
                variable = v,          # 關鍵點：共享同一個變數
                value = i,             # 關鍵點：每個選項的真實數值不同
                text = arr[i],         # 畫面上顯示的文字
                command = show_choice  # 點擊時即時觸發
    ).pack()

7.2 經典雷區：多個獨立 Radiobutton 群組連動錯誤與正確解法

多群組錯誤原因：如果畫面上有「性別」和「科系」兩組完全不相關的單選題，但兩者都使用了同一個 v = IntVar()，那麼點擊性別時，科系也會莫名其妙被取消或連動變更。
# 正確解法：宣告多個獨立的 Var 變數 (講義第13頁)
v1 = IntVar(); v1.set(0)               # 第一組專用變數
v2 = IntVar(); v2.set(0)               # 第二組專用變數

# 建立第一組 (系所群組)
for i in range(3):
    Radiobutton(root, variable=v1, value=i, text="系所選項"+str(i)).pack()
    
# 建立第二組 (性別/其他群組)
for i in range(3):
    Radiobutton(root, variable=v2, value=i, text="其他群組選項"+str(i)).pack()

7.3 indicatoron 參數應用 — 將單選鈕偽裝成高質感一般按鈕

設定 indicatoron=0 後，傳統的小圓圈會消失。元件外觀會直接變成普通按鈕，當被選中時會保持凹陷狀態 (SUNKEN)，非常適合用於導覽列或頁籤切換設計。

v = IntVar(); v.set(0)
for i in range(3):
    Radiobutton(root, 
                variable=v, 
                value=i, 
                indicatoron=0,         # 關閉傳統圓圈指針指示符號
                text="頁籤 " + str(i)
    ).pack(fill=X)

CH06. OptionMenu 下拉選單組件與頂層高階 Menubar 視窗選單設計

當選項過多、不適合用 Radiobutton 鋪滿畫面時，OptionMenu（下拉選單）是最佳的空間節省方案。

8.1 OptionMenu 下拉選單兩種宣告方式

# 宣告型式一：直接列出所有選項字串
v1 = StringVar(root)
v1.set("電子系")                         # 設定初始被選中值
om1 = OptionMenu(root, v1, "電子系", "電機系", "資工系")
om1.pack()

# 宣告型式二：利用 Python 串列展開語法 * (極度實用，講義第2頁)
department = ["電子系", "電機系", "資工系", "機械系", "化工系"]
v2 = StringVar(root)
v2.set(department[0])
om2 = OptionMenu(root, v2, *department) # * 號會自動將串列解包為個別的參數傳入
om2.pack()

8.2 即時事件回呼 (選取選單時直接觸發函式)

OptionMenu 的 command 參數綁定之函式，系統會自動附帶傳入一個「目前被選中項目的字串值」參數，因此函式必須宣告一個接收參數。

def on_select_change(selected_value):
    print("用戶剛剛選擇切換到了:", selected_value)

om = OptionMenu(root, v, *department, command=on_select_change)
om.pack()

8.3 視窗頂部高階選單列 (Menubar) 標準架構模板

這是在專業桌面軟體最頂層看見的「檔案(File)」、「說明(Help)」下拉階層選單組合。基本原理是主選單列下挂載多個子 Menu 物件。

def About():
    print("這是選單程式設計的範例說明")

root = Tk()

# 1. 初始化最頂層的方塊總選單列主物件
menubar = Menu(root)

# 2. 初始化第一個下拉清單物件 (File 內部選單)
filemenu = Menu(menubar, tearoff=0) # tearoff=0 可以關閉 Tkinter 預設的選單分離線
filemenu.add_command(label="Open...", command=lambda: print("開啟檔案..."))
filemenu.add_command(label="Exit", command=root.quit)
# 將 File 下拉清單以級聯 (cascade) 方式掛載到總選單列上
menubar.add_cascade(label="File", menu=filemenu)

# 3. 初始化第二個下拉清單物件 (Help 內部選單)
helpmenu = Menu(menubar, tearoff=0)
helpmenu.add_command(label="About...", command=About)
menubar.add_cascade(label="Help", menu=helpmenu)

# 4. 最重要的一步：將配置好的總選單列物件反向指派給 root 主視窗
root["menu"] = menubar
root.mainloop()

8.4 互動式 filedialog 系統開檔對話框

點選選單觸發時，跳出 Windows 原生的選擇檔案視窗，並過濾特定的副檔名，最終取得完整的檔案絕對路徑。

from tkinter import *
from tkinter import filedialog

# 開檔函式
def OpenFile():
    # 參數說明：initialdir 預設開啟目錄, title 對話框上方名稱, filetypes 過濾檔案格式
    file_path = filedialog.askopenfilename(
        initialdir = "C:/",
        title = "請選擇您的圖片檔案",
        filetypes = (("jpeg 檔案","*.jpg"), ("全部檔案","*.*"))
    )
    if file_path:
        print("使用者選擇的檔案路徑為：", file_path)

# 彈出說明訊息的函式
def About():
    print("This is a simple example of a menu")

root = Tk()                      # 建立視窗
menu = Menu(root)                # 初始化主選單列主物件

# 初始化第一個下拉清單物件 (File 內部選單)
filemenu = Menu(menu, tearoff=0)
# 新增 Open... 與 Exit 選項至 File 方塊選項中，並綁定對應的函式
filemenu.add_command(label="Open...", command=OpenFile)
filemenu.add_command(label="Exit", command=root.quit)
# 將 File 下拉清單以級聯 (cascade) 方式掛載到總選單列上
menu.add_cascade(label="File", menu=filemenu)

# 初始化第二個下拉清單物件 (Help 內部選單)
helpmenu = Menu(menu, tearoff=0)
helpmenu.add_command(label="About...", command=About)
menu.add_cascade(label="Help", menu=helpmenu)

root["menu"] = menu              # 將配置好的總選單列物件指派給 root 主視窗
root.mainloop()

CH07. 專題實戰必備：進階與隱藏版技巧 (針對作業03~11)

老師在作業中加入了許多遊戲與資料庫機制，以下是完成這些作業必須掌握的進階語法：

9.1 鍵盤 Enter 鍵綁定 (作業08、09 打字遊戲必備)

不使用按鈕，而是透過鍵盤輸入完成後直接按下 Enter 鍵來觸發對答案的檢查。

# 被綁定的事件函式必須接收一個 event 參數
def check_answer(event):
    user_input = entry.get()
    if user_input == "apple":
        print("答對了！")
        entry.delete(0, END)  # 答對後自動清空輸入框

entry = Entry(root)
entry.pack()
# <Return> 代表鍵盤上的 Enter 鍵
entry.bind("<Return>", check_answer)

9.2 畫面不卡死！非同步延遲機制 (作業05、06、07 必備)

在配對遊戲中（翻錯要等一秒蓋回去）或打地鼠遊戲中（地鼠自動消失），絕對不能使用 time.sleep()，否則整個視窗會當機死當。必須使用 Tkinter 的 after() 方法。

# 配對遊戲：翻錯牌時，延遲 500 毫秒(0.5秒)後蓋回，期間不卡死畫面
def flip_back(btn1, btn2):
    btn1.config(text="")
    btn2.config(text="")

# 假設玩家按錯了...
# 延遲 500 毫秒後，執行 flip_back 函式，並傳入 btnA, btnB 作為參數
root.after(500, flip_back, btnA, btnB)

9.3 動態清空畫面上的所有元件 (作業04 過關擴大九宮格必備)

當遊戲進入下一關，原本的 3x3 九宮格要變成 4x4，你必須先把舊的按鈕全部清除乾淨再重新排列。

# 取得 root (或某個 Frame) 內部的所有子元件，並將它們全數銷毀
for widget in root.winfo_children():
    widget.destroy()

# 銷毀後即可重新跑 for 迴圈建立新的 4x4 網格

9.4 Entry 的直接清空與寫入 (作業10、11 資料表 CRUD 必備)

在製作「新增」或「上一筆/下一筆」功能時，我們需要頻繁清空輸入框並塞入新資料。除了用 StringVar()，最直接的方法是使用 delete 與 insert。

entry = Entry(root)
entry.pack()

# 1. 清空輸入框 (從第 0 個字元刪除到最後 END)
entry.delete(0, END)

# 2. 寫入新資料 (在第 0 個位置插入字串)
entry.insert(0, "王大明")
